## 🌟 What is Foodie?

**Foodie** is a modern, full-stack food discovery and ordering platform designed to bring the complete food experience into one beautiful ecosystem.

It combines:

🍽️ **Food Discovery**
🔎 **Smart Search & Filtering**
❤️ **Wishlist & Favorites**
🛒 **Online Food Ordering**
💬 **Community Comments**
💡 **Cooking Ideas & Recipes**
🎬 **Short Food Videos**
☕ **Cafe Management**
🛡️ **Admin Dashboard**

> **Foodie isn't just a food ordering website — it's a complete food discovery ecosystem.**

# 🛡️ Admin Mode — Zero Database

Foodie provides a lightweight admin server that can run **without PostgreSQL**.

Perfect for:

* 🎨 UI demonstrations
* 🧪 Local testing
* 🖥️ Frontend development
* 📊 Admin dashboard testing

Open another PowerShell terminal:

```powershell
$env:PORT = "8080"
$env:FOODIE_ADMIN_EMAIL = "your-admin-email"
$env:FOODIE_ADMIN_PASSWORD = "choose-a-strong-password"

pnpm --filter @workspace/api-server run admin
```

Then open:

```text
http://localhost:5173/admin/login
```

### Admin Session Model

```text
Admin Login
     │
     ▼
Server Authentication
     │
     ▼
In-Memory Session
     │
     ▼
8 Hour Session
     │
     ▼
Server Restart
     │
     ▼
Session Invalidated
```

### ⚠️ Admin-only Mode Limitations

In this mode:

* Sessions are stored in memory
* Sessions expire after approximately 8 hours
* Restarting the server invalidates sessions
* Dashboard changes are stored in browser local storage
* Changes are not shared between browsers
* Persistent accounts and orders are unavailable

# 🗄️ Full Production-Style API

For complete database-backed functionality, configure PostgreSQL.

Required environment variables:

```text
DATABASE_URL
SESSION_SECRET
```

Start the API:

```powershell
$env:PORT = "8080"
$env:DATABASE_URL = "your-postgresql-connection-url"
$env:SESSION_SECRET = "your-private-user-session-secret"

pnpm --filter @workspace/api-server run dev
```

For admin authentication:

```powershell
$env:FOODIE_ADMIN_EMAIL = "your-admin-email"
$env:FOODIE_ADMIN_PASSWORD = "your-admin-password"
```

# 🔐 Environment Configuration

Create your environment configuration using:

```env
PORT=8080

DATABASE_URL=your-postgresql-connection-url

SESSION_SECRET=your-private-session-secret

FOODIE_ADMIN_EMAIL=your-admin-email

FOODIE_ADMIN_PASSWORD=your-admin-password
```

### 🔒 Security Rules

> **Never commit production credentials to GitHub.**

Recommended `.gitignore`:

```gitignore
.env
.env.local
.env.production
node_modules/
dist/
```

For production deployment, configure secrets through your hosting provider.
